# 🏠 SmartHome — Система умного дома для МКД

## 📋 Общая информация

**Проект:** Система мониторинга температуры стояков ГВС (горячего и холодного водоснабжения) для многоквартирного дома  
**Здание:** МКД, 40 квартир, 10 этажей  
**Базовая платформа:** SprutHub CE (Система 3.0.0b, прошивка 20260814_1639_spruthub2)  
**Контроллеры:** ESP32 с датчиками DS18B20  
**Дата создания:** 18 сентября 2026  
**Статус:** 🟢 Активная разработка

---

## 🎯 Цель проекта

Разработать масштабируемую систему мониторинга температуры на стояках горячего и холодного водоснабжения для выявления:
- Аварийных ситуаций (перегрев/понижение температуры)
- Несанкционированного подключения к стоякам
- Потерь тепла и утечек
- Разницы температур между подачей и обраткой

## 📦 Оборудование

### 1. Контроллеры ESP32

| Параметр | Значение |
|----------|----------|
| Модель | ESP32 DevKit v1 (30-pin) |
| Чип | ESP32-D0WD-V3 (240 MHz, Dual Core) |
| Wi-Fi | 802.11 b/g/n |
| Bluetooth | BLE + Classic BT |
| USB | CH340C |
| Антенна | PCB (печатная, встроенная) |
| LED индикация | GPIO 2 (встроенный) |

**Проблема:** Металлический щиток экранирует Wi-Fi сигнал. Требуется тестирование сигнала в подвале.

### 2. Датчики температуры

| Параметр | Значение |
|----------|----------|
| Модель | DS18B20 (металлический корпус) |
| Протокол | 1-Wire |
| Точность | ±0.5°C (в диапазоне -10...+85°C) |
| Разрешение | 12 бит (0.0625°C) |
| Питание | 3.3V - 5V |
| Резистор | 4.7 кОм (подтяжка DATA к VCC) |

**Подключение:**
- Один датчик на подачу (горячая вода)
- Один датчик на обратку (холодная вода)
- На каждый стояк — своя пара датчиков + свой ESP32

### 3. Сеть

| Параметр | Значение |
|----------|----------|
| Протокол | Wi-Fi 2.4 GHz |
| MQTT брокер | Встроенный в SprutHub CE |
| MQTT порт | 44444 |
| Формат топиков | WirenBoard |

## 📡 Протокол связи

### MQTT Топики

**Формат:** `SprutHub/<ИмяУстройства>-<Позиция>/DS18B20/temperature`

| Топик | Описание | Пример значения |
|-------|----------|-----------------|
| `SprutHub/St01-P/DS18B20/temperature` | Ст01 Подача (горячая) | `39.50` |
| `SprutHub/St01-O/DS18B20/temperature` | Ст01 Обратка (холодная) | `27.20` |

**Где:**
- `St01` — номер стояка/ESP32
- `P` — Подача (подающая труба)
- `O` — Обратка (обратная труба)

### Формат данных

Текстовое значение температуры в °C (например: `39.50`)

### Last Will & Testament (LWT) — В ПЛАНЕ

**Топик статуса:** `devices/<ИмяУстройства>/status`  
**Значения:** `online` / `offline`  
**Назначение:** Автоматическое обнаружение отключения устройства

## 🔌 Подключение датчиков

### Схема подключения DS18B20

```
        3.3V (или 5V)
          │
         ┌┴┐
         │ │ 4.7 кОм
         └┬┘
          │
DATA ─────┼─────── GPIO 4 (ESP32)
          │
     ┌────┴────┐
     │ DS18B20 │
     └────┬────┘
          │
         GND
```

### Адреса датчиков (Ст01)

| Позиция | Адрес | Температура (при тесте) |
|---------|-------|------------------------|
| Подача | `28:74:59:15:00:00:00:85` | ~39°C |
| Обратка | `28:EE:F2:14:00:00:00:37` | ~27°C |

**Примечание:** Адреса — заводские, не зависят от порядка подключения.

## 🎛 Индикация (LED на GPIO 2)

### 1. Качество Wi-Fi

| RSSI | Поведение LED | Оценка |
|------|--------------|--------|
| -30...-50 dBm | Горит постоянно | Отлично |
| -50...-60 dBm | Мигает 1 раз в 2 сек | Хорошо |
| -60...-70 dBm | Мигает 1 раз в 3 сек | Средне |
| -70...-80 dBm | Мигает 1 раз в 5 сек | Слабо |
| <-80 dBm | Не мигает | Критически слабо |
