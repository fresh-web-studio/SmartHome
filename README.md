# 🏠 SmartHome — Система умного дома для МКД

## 📋 Общая информация

**Проект:** Система мониторинга температуры стояков ГВС (горячего и холодного водоснабжения) для многоквартирного дома  
**Здание:** МКД, 40 квартир, 10 этажей  
**Базовая платформа:** SprutHub CE (Система 3.0.0b, прошивка 20260814_1639_spruthub2)  
**Контроллер:** 1x ESP32 с 4 шинами 1-Wire, 11 датчиков DS18B20  
**Дата создания:** 18 сентября 2026  
**Дата последнего обновления:** 3 октября 2026  
**Статус:** 🟢 Активная разработка + переход на Ethernet

---

## 🎯 Цель проекта

Разработать масштабируемую систему мониторинга температуры на стояках горячего и холодного водоснабжения для выявления:
- Аварийных ситуаций (перегрев/понижение температуры)
- Несанкционированного подключения к стоякам
- Потерь тепла и утечек
- Разницы температур между подачей и обраткой

## 📦 Оборудование

### 1. Контроллер ESP32

| Параметр | Значение |
|----------|----------|
| Чип | ESP32-D0WD-V3 (240 MHz, Dual Core) |
| Wi-Fi | 802.11 b/g/n |
| Bluetooth | BLE + Classic BT |
| USB | CH340 |
| Антенна | PCB (печатная, встроенная) |
| LED индикация | GPIO 2 (встроенный) |

**Архитектура:** Один ESP32 обслуживает все стояки через 4 шины 1-Wire:
- GPIO4 — Ветка 1 (St01-St05, Outdoors)
- GPIO16 — Ветка 2 (St06-St08)
- GPIO17 — Ветка 3 (St09-St13)
- GPIO18 — Ветка 4 (St14-St17, TU)

**Проблема:** Металлический щиток экранирует Wi-Fi сигнал. Планируется переход на Ethernet.

### 2. Датчики температуры

| Параметр | Значение |
|----------|----------|
| Модель | DS18B20 (металлический корпус) |
| Протокол | 1-Wire |
| Точность | ±0.5°C (в диапазоне -10...+85°C) |
| Разрешение | 12 бит (0.0625°C) |
| Питание | 3.3V - 5V |
| Резистор подтяжки | **1 кОм** (на ВСЕХ 4 ветках) |

**Всего датчиков:** 11 штук (22 измерения — подача + обратка для каждого стояка)

**Подключение:**
- Один датчик на подачу (горячая вода)
- Один датчик на обратку (холодная вода)
- На каждый стояк — своя пара датчиков
- Все датчики подключены к одному ESP32 через 4 шины 1-Wire

### 3. Сеть

| Параметр | Значение |
|----------|----------|
| Протокол | Wi-Fi 2.4 GHz / Ethernet (W5500) |
| MQTT брокер | Встроенный в SprutHub CE |
| MQTT порт | 44444 |
| Формат топиков | WirenBoard |

### 4. W5500 Ethernet Shield

| Параметр | Значение |
|----------|----------|
| Статус | 🟡 В процессе внедрения |
| Назначение | Замена Wi-Fi на стабильное Ethernet подключение |
| Причина | Экранирование Wi-Fi металлическим щитком |

## 📡 Протокол связи

### MQTT Топики

**Формат:** `SprutHub/<ИмяУстройства>-<Позиция>/DS18B20/temperature`

| Топик | Описание | Пример значения |
|-------|----------|-----------------|
| `SprutHub/St01-P/DS18B20/temperature` | Ст01 Подача (горячая) | `39.50` |
| `SprutHub/St01-O/DS18B20/temperature` | Ст01 Обратка (холодная) | `27.20` |
| `SprutHub/St02-P/DS18B20/temperature` | Ст02 Подача | `...` |
| `SprutHub/St02-O/DS18B20/temperature` | Ст02 Обратка | `...` |
| ... | ... | ... |
| `SprutHub/St17-P/DS18B20/temperature` | Ст17 Подача | `...` |
| `SprutHub/St17-O/DS18B20/temperature` | Ст17 Обратка | `...` |
| `SprutHub/TU-P/DS18B20/temperature` | ТеплоУзел Подача | `...` |
| `SprutHub/TU-O/DS18B20/temperature` | ТеплоУзел Обратка | `...` |
| `SprutHub/Outdoors-P/DS18B20/temperature` | Температура улицы | `...` |

**Всего топиков:** 35 (17 стояков × 2 + TU × 2 + Outdoors)

**Где:**
- `St01`-`St17` — номер стояка
- `TU` — ТеплоУзел
- `Outdoors` — температура улицы
- `P` — Подача (подающая труба)
- `O` — Обратка (обратная труба)

### Формат данных

Текстовое значение температуры в °C (например: `39.50`)

### Last Will & Testament (LWT) — В ПЛАНЕ

**Топик статуса:** `devices/<ИмяУстройства>/status`  
**Значения:** `online` / `offline`  
**Назначение:** Автоматическое обнаружение отключения устройства

## 🎛 Индикация (LED на GPIO 2)

### 1. Качество Wi-Fi

| RSSI | Поведение LED | Оценка |
|------|--------------|--------|
| -30...-50 dBm | Горит постоянно | Отлично |
| -50...-60 dBm | Мигает 1 раз в 2 сек | Хорошо |
| -60...-70 dBm | Мигает 1 раз в 3 сек | Средне |
| -70...-80 dBm | Мигает 1 раз в 5 сек | Слабо |
| <-80 dBm | Не мигает | Критически слабо |

## 🐍 Python скрипт мониторинга

### watch_temp.py

Скрипт для мониторинга температуры стояков в реальном времени через MQTT.

**Функции:**
- Подписка на топики St01-St17, TU, Outdoors
- Отображение температуры подачи, обратки и разницы (Δ)
- Статистика сессии при выходе (Ctrl+C)

**Как запустить:**

```bash
cd /Users/mac/Sites/Projects/SmartHome/esp32-temp-sensor
python3 watch_temp.py
```

**Пример вывода:**
```
[0001] 2026-10-03 15:30:00  St01:  39.50°C/ 27.20°C (Δ 12.30°C)
[0002] 2026-10-03 15:30:00  St02:  38.80°C/ 26.90°C (Δ 11.90°C)
...
```

**Требования:**
- Python 3
- Библиотека `paho-mqtt`
- Файл `config.py` с настройками MQTT
